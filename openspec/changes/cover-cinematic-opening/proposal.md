# Proposal: Cover Cinematic Opening
Generated by: cm-planning
Date: 2026-05-26

## Why we're doing this

The user asked for a cinematic opening where multiple images float in from far away, then converge. The right place is the cover because it creates a memorable first impression without adding spectacle to every content slide.

## Options Evaluated

### Option A: Use Abstract Cards

Floating text-only cards would be lightweight and reliable.

- Pros: no asset dependency, very fast
- Cons: weaker cinematic impact

### Option B: Use Existing Project Images

Floating image cards use current assets: Codex, Antigravity, Claude Code, Ocean USB Builder and skill imagery.

- Pros: visually rich, grounded in deck content
- Cons: needs careful timing so cards do not cover the workflow diagram

### Option C: Full-Screen Image Storm

Images fill the viewport, then collapse toward the title.

- Pros: strongest spectacle
- Cons: too distracting for an internal operator briefing

## Recommendation

Choose Option B.

The cinematic moment should start as evidence cards floating in 3D on the cover visual, then collapse into the workflow area and fade out so the final cover remains clean and presenter-friendly.

## Scope

- Cover slide only.
- No change to other slide animations.
- No new media generation.
- Use transform/opacity/filter only.
- Respect reduced-motion.
