# Calm Executive Briefing Design Pass

## Goal

Make the whole deck feel easier to watch for a technical and operations audience: practical, confident, and calm. The deck should still feel like an AI Agent Playbook, but it should no longer read as a sequence of loud dashboard cards.

## Direction

- Keep Sea navy as the authority color, Sea blue as the system/progress color, and Shopee orange as the decision/safety/action accent.
- Use orange sparingly. It should mark proof, risk, demo relevance, or final decision points.
- Reduce visual fatigue: softer borders, lighter shadows, fewer heavy top borders, fewer repeated icon glints.
- Prefer structured briefing layouts over decorative cards.
- Keep cards only for repeated items, anchored demo diagrams, and framed decision blocks.
- Make icons functional: chart for evidence, route for journey, wrench/tool for real output, shield/stop icons for guardrails.
- Keep motion presenter-controlled and brief. Animation should guide attention, not entertain by itself.

## Deck-Level Rules

- Light content slides use white or very pale blue panels with thin navy-tinted borders.
- Dark slides are reserved for major chapter anchors: cover, demo emphasis, and Q&A.
- Slide titles use Outfit, strong but not over-heavy. Body uses Open Sans with readable weight.
- The recurring top accent line should stay subtle and shorter than the title area.
- Footer brand text should be quiet and should not compete with content.
- Sources should be visually secondary.

## Specific Fixes

- Slide 3 should feel like the evidence-backed promise for the session, not a survey dashboard. The bottom proof strip should say "Case thuc te" rather than "Demo duy nhat".
- Slide 10 should make Ocean USB Builder feel like the concrete output of the method, but the diagram container should be less visually heavy.
- Guardrail slides should not use orange for every icon. Orange should point to the highest-risk stop moments.
- Q&A should feel like a calm closeout, not a mostly empty dark card.

## Handoff Note

Do not reintroduce "Demo duy nhat" as visible slide copy. It is only presenter context. Audience-facing wording should be "Case thuc te", "demo chinh", or "Ocean USB Builder".
