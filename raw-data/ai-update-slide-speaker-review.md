# AI Update Slide Speaker Review

> **Captured**: 2026-05-25  
> **Applies To**: Slide 4, "AI Update 2026: Từ Chatbot Sang Agent".

## Core Diagnosis

The slide is visually clean and has the right four trends, but it reads more like a status report than a stage-ready opening argument. It needs one memorable claim, less body text, a clearer sequence and an explicit "so what" for the team.

## Improvements To Apply

1. **One message**
   - Make the central claim clear: AI has moved from answering in chat to acting inside real workflows.

2. **Shorter card copy**
   - Each card should have one strong headline and one compact proof line.
   - Move longer explanations into speaker notes.

3. **Linear story**
   - Reframe the four cards as a chain:
     - Model mạnh hơn.
     - Agent làm task end-to-end.
     - Tool ecosystem đưa đúng context vào workflow.
     - Governance kiểm soát rủi ro.

4. **So what for the team**
   - Add a final takeaway:
     - "Câu hỏi mới không phải AI trả lời gì, mà là Agent được phép làm gì và kiểm chứng ra sao."

5. **Reduce jargon**
   - Explain MCP, connector and governance by meaning:
     - Current docs, repos, APIs and internal tools.
     - Access, approval, logs, audit and sandbox.

6. **Add dates to sources**
   - Keep sources short but time-stamped:
     - OpenAI GPT-5.5/Codex, Apr 2026.
     - Google MCP/Managed Agents, Apr-May 2026.
     - Microsoft Agent 365, Mar 2026.
     - Anthropic Claude Code, 2026.

## Suggested Copy

**Title**

AI Update 2026: Từ Chatbot Sang Agent

**Subtitle**

Model không chỉ thông minh hơn. Chúng bắt đầu đọc file, dùng tool, chạy task dài và cần cơ chế kiểm soát.

**Cards**

1. Model làm việc dài hơi hơn  
   Code, research, data, documents, software operation.

2. Coding agent nhận task end-to-end  
   Đọc repo -> lập plan -> sửa file -> chạy test -> review diff.

3. Tool ecosystem thành hạ tầng mới  
   MCP, connector, skill giúp Agent lấy đúng context và dùng đúng công cụ.

4. Governance trở thành bắt buộc  
   Quyền truy cập, approval gate, log, audit, sandbox.

**Takeaway**

Câu hỏi mới không phải "AI trả lời gì?", mà là "Agent được phép làm gì và kiểm chứng ra sao?"
